# Space Portfolio — Maria Zenina

An interactive 3D portfolio: you fly through space, a forest, the sea, and down to the beach,
and every part of the journey opens a section of my story — about me, skills, education,
projects, and designs.

**Live site:** https://ilge1000.github.io/space-portfolio/

## What's inside

- A camera flight along a path through four zones, controlled with the keyboard (W / S),
  the mouse wheel, or by holding the left / right side of the screen on a phone
- Scenes built from particle clouds sampled from my own Blender models
- Section cards opened by "messengers": shooting stars, a falling leaf, a bird, jumping
  dolphins, a lighthouse beam, and a letter from a mailbox — with fireworks at the end
- Zone music, a quick "Fast check" view of all sections, and a direct "Contact now" flight

## Built with

React 19 · Vite · Three.js · React Three Fiber · drei · postprocessing (bloom) · Blender

## Run locally

```bash
npm install
npm run dev
```
